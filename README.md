# EUROPOOR — Directorate-General for Decline

Satire built on real news and official statistics. Plain HTML, CSS and JavaScript:
no framework, no build step, no dependencies.

## What's in it

| Route | What it is |
|---|---|
| `#/` | Front page: the crumbling-star index, a live EU debt clock, the latest filings, the index, the map, the league and the games |
| `#/wire` | **The Wire**, a live feed of setback news (government, inflation, economy, jobs, energy, debt, housing, cost of living) with filters and auto-refresh |
| `#/index` | The Europoor Index: today's score, history since 2000, country ranking, what moved it, method |
| `#/data` | Data hub: 31 countries × 12 official measures. Sort, filter by region or currency, pin countries, latest / 1-year / 5-year view, CSV download |
| `#/data/<country>` | One country's figures against the EU average, with charts |
| `#/league` | The Decline League: 7 days / 28 days / season, form, movement, zones |
| `#/country/<country>` | The country's dossier: league week, filings, numbers |
| `#/map` | Tile map of Europe, coloured by the index or any measure |
| `#/play` | Three daily games (Poorer or Richer?, Europoordle, Real or Satire?) with streaks, share grids and achievements stored on the player's device |

## Run it locally

```bash
python3 -m http.server 8000      # then open http://localhost:8000
```

Opening `index.html` straight from disk also works. The seed data is loaded from `data/*.js`, but the
wire only polls for new filings when the site is served over http(s).

## Keeping it live

Both scripts use only the Python 3 standard library.

```bash
python3 scripts/fetch_news.py            # sweep the news, rewrite data/news.json + news.js (about 1–3 min)
python3 scripts/fetch_news.py --loop 15  # on a VPS: sweep every 15 minutes, forever
python3 scripts/fetch_data.py            # Eurostat + national offices, rewrite data/data.json + data.js (about 40 s)
```

Open pages poll `data/news.json` every 60 seconds. New filings show up with a "new filings"
notice, and the ticker rebuilds itself.

**Static hosting (GitHub Pages, Netlify, Cloudflare Pages):** `.github/workflows/refresh.yml`
runs the news sweep every 15 minutes and the statistics refresh once a day, then commits
`data/` back to the repo, which triggers a redeploy.

**A VPS:** serve the folder with nginx or Caddy and run `fetch_news.py --loop 15` under
systemd or in tmux, plus a daily cron job for `fetch_data.py`.

**Netlify + GitHub (the live setup):** Netlify is connected to this repository and serves the site. `netlify.toml` skips deploys for commits that only change `data/`. The refresh workflow commits new data here, and open pages read it from the address in `window.EP_FEED` in `index.html`. If you fork or rename the repository, change that address.

**The claude.ai preview link does not update by itself.** Its files only change when someone publishes them, and scheduled sessions can't publish. Real hosting, as above, is what makes the wire live.

## Where the numbers come from

- **Statistics:** Eurostat (HICP, unemployment, national accounts, government finance, energy prices,
  house prices, PPPs and industrial production). Gaps are filled from ONS (UK), OECD, the IMF,
  Ofgem and ElCom. Hand-entered values live in `scripts/manual.json`, each with its source URL.
  The Swiss 2025 electricity tariff in that file was recalled rather than looked up, so check it before launch.
- **Index:** each of six measures is scored `50 + 15 × z` against its 2000–2019 average. The EU is scored
  against its own history. Countries are scored against a pooled baseline across all 31 countries.
  The full method is on `#/index`.
- **News:** headlines and links come from publishers, found through Google News RSS. Headlines are never
  edited. The category, severity, points and the red-ink memo are added by the Directorate.
  Note that Google's RSS terms cover personal, non-commercial use. If the site makes money, switch the sweeper
  to publishers' own RSS feeds or a licensed news API.
- **Debt clock:** an estimate, labelled as one on the page. The constants are in `CLOCK` in `assets/js/app.js`.
  Update them when Eurostat publishes a new quarter.
